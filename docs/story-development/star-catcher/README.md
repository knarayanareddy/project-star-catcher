# Star Catcher
## Original project — review and production reference

**Existing registered arc:** four episodes, 14:30 total. The original README describes the five-minute first film; the current episode registry includes all four.

This folder groups the development review and gives you a single entry point into the original project's production files. **The working application, rendering engines, subtitles, and existing audio have not been moved**, because relocating them would risk breaking imports and playback paths. They are not new assets generated by the later story-development work.

## Read first

[Arc review](arc-review.md) — reconstruction of the four-episode story, its strengths, ambiguity/causality issues, motif development, and lessons for the later projects. It is a review of repository story material, not a new screenplay or a frame-by-frame viewing assessment.

## Using this storyline as a reference

Read the review for the emotional arc, use the episode definitions and chapters for current structure, and use the SRT/VTT files for the existing narration text and timing. Do not treat planning-era episode statuses in the original film timeline as the current release state; the current registry and episode definitions determine playback.

This is the one folder that intentionally points to production assets outside itself. The five newly developed storylines keep their authored story materials inside their own folders.
