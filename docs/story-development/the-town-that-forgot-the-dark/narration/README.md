# The Town That Forgot the Dark — narration only

**Narrator:** Iona Senn. One mature feminine voice: warm public-service delivery, becoming more candid without losing clarity.

These six text files contain only spoken words. Each has five paragraphs, one for each 45-second picture beat in the [series bible](../series-bible.md). Generate paragraphs separately, then build pauses, action, music, and sound in the edit. Titles and production directions are not spoken.

1. [Good Night, Productive Citizens](01.txt)
2. [Additional Rest](02.txt)
3. [The Things We Dream for Free](03.txt)
4. [A Rehearsal for Night](04.txt)
5. [One Hour](05.txt)
6. [The Unread Page](06.txt)

Each episode allocates 3:45 to story and 0:15 to its end card. Actual runtime still needs a timed performance and animatic. No audio has been synthesized by this package.

To change dialogue, edit the bible and run `python prepare_narration.py --write` from the parent storyline folder. To verify these exports are current, run the same command with `--check` instead.
