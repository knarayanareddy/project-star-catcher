# The Republic of Tomorrow
## Start here — storyline development folder

**Format:** six episodes × 10 minutes.
**Genre:** Civic conspiracy thriller / deterministic satire.
**Premise:** A forecaster must expose a safety model that manufactures its own certainty and organize a physically workable evacuation.

## Authoritative reference

[Open the complete series bible](series-bible.md). It contains the ideology, economy, operational rules, principal characters and relationships, season causality, all six timed episode outlines, setup/payoff map, continuity stress tests, and audiovisual/production notes.

This folder contains all material already written for this storyline. No other storyline is needed to understand it.

## Development status — important

**Completed:** detailed series treatment and six episode outlines.

**Not yet written or produced:** scene-by-scene expansion, complete dialogue screenplays, narration-only scripts, generated voices/music/images, or finished video. Do not mistake timed outlines for production-ready scripts.

## How to use this folder for further generation

1. Supply `series-bible.md` as the story reference.
2. Ask for expansion of one specified episode while preserving all six episodes' rules and payoffs.
3. Write and review a full scene treatment, then a dialogue screenplay, before generating final actor audio.
4. Build a cast/voice register and continuity ledger during that expansion. This is a dialogue-capable ensemble series, not the single-narrator format of the shorter projects.
5. Test performed runtime rather than assuming the outlined timecodes guarantee ten minutes.

No empty script folders or unwritten placeholder files have been added. This index distinguishes the material that exists from the next development steps.
