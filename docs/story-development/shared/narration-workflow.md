# Narration-only scripts

These twelve text files contain **only spoken words**, five paragraphs per episode, in the order of the source document's five 45-second picture beats. They contain no spoken titles, directions, or credits.

For production, generate each paragraph as its own clip and retain the five-beat timing map in the main treatment. Do not ask the voice generator to manufacture all the intervening silence. Build that time in the edit using picture, ambience, effects, and restraint.

### Special cue in the moth series

In episode 5, the isolated return cue is a fresh, deliberate instruction. These are editing assets, not another character or a requirement to speak the entire narration into the town's PA. Iona's ordinary diary narration is separate from that system.

### Source and maintenance

Each storyline folder's `series-bible.md` is its authored source. Each folder also has its own independent `prepare_narration.py`; neither series needs the other to validate or regenerate exports. These text files are extracted copies, not independently revised dialogue drafts.

To regenerate them after editing the source:

```bash
python docs/story-development/the-department-of-missing-rooms/prepare_narration.py --write
python docs/story-development/the-town-that-forgot-the-dark/prepare_narration.py --write
```

To check all twelve episodes, timing windows, links, and current exports:

```bash
python docs/story-development/the-department-of-missing-rooms/prepare_narration.py --check
python docs/story-development/the-town-that-forgot-the-dark/prepare_narration.py --check
```

No audio is generated by either command. There are 3,320 spoken-script words in this draft across both seasons; final performance duration remains untested.
